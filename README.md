# Personal Portfolio

This repository contains the source code for a comprehensive, full-stack personal portfolio application. It is designed for academics, researchers, and software developers to showcase their projects, publications, and professional background.

The project features a public-facing website with a modern, responsive design, alongside a secure, built-in admin dashboard. From the admin dashboard, the owner can dynamically manage and edit all content on the site, including biographical information, project listings, research highlights, publications, contact form messages, and social links. The application is highly configurable, allowing specific sections to be hidden or displayed, accent colors to be changed, and site copy to be edited — all from the admin UI.

For detailed information on the architecture, local development setup, and deployment instructions, please refer to the [Documentation](DOCUMENTATION.md).

## Tech Stack

The application is built using a modern, serverless architecture split into a frontend client and a backend API.

### Frontend
- **Framework**: React 19 with TypeScript
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS v4
- **Routing**: React Router v7
- **Animations**: GSAP (GreenSock Animation Platform) + Lenis (smooth scrolling)
- **Forms**: React Hook Form
- **Icons**: Material Symbols Rounded

### Backend
- **Framework**: Hono (running on Cloudflare Workers)
- **Runtime**: Cloudflare Workers
- **Validation**: Zod v4 (schema validation for all API inputs)
- **Authentication**: JWT (JSON Web Tokens) delivered via `httpOnly`, `Secure`, `SameSite=None`, `Partitioned` cookies with bcrypt for password hashing. Passwords are securely stored in a dedicated Cloudflare KV namespace (`AUTH_STORE`).
- **Storage**: Cloudflare R2 Object Storage (used as a lightweight NoSQL database for JSON configurations, contact messages, and image hosting).
- **Rate Limiting**: Cloudflare Durable Objects are used for atomic, persistent IP-based rate limiting across login, contact form, and password change endpoints.
- **Email Notifications**: Resend API (used to send admin notifications for contact form submissions).
- **Image Uploads**: Magic-byte content sniffing validates uploads against a strict MIME allowlist (JPEG, PNG, WEBP, GIF only).
- **Security**: `secureHeaders` middleware, `X-Content-Type-Options: nosniff`, per-request CSP nonces via Cloudflare Pages Functions middleware, and explicit CORS allowlisting.
- **Testing**: Vitest

### Deployment
- **Hosting**: Cloudflare Pages (Frontend) and Cloudflare Workers (Backend)
- **CI/CD**: GitHub Actions for automated building and deployment
- **CSP**: Dynamic per-request nonces generated by a Cloudflare Pages Functions middleware (`functions/_middleware.ts`) to support Cloudflare's injected scripts (Bot Fight Mode / Browser Integrity Check)
